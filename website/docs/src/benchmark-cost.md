# Archived Cost Analysis

> **Retired on July 28, 2026.** The former page applied an approximate
> byte-to-token conversion and March 2026 model-price assumptions to a 49-URL
> exploratory sample. Its underlying per-input report, tokenizer identity,
> corpus digest, commit, runner provenance, and complete outcomes were not
> retained to today's evidence standard.

The former ratios, token estimates, dollar figures, and scale extrapolations are
not current Plasmate claims and should not be cited.

Serialized-byte reduction does not translate mechanically into token usage,
model cost, latency, retained information, or task success. A valid cost study
must:

1. retain every attempted input and outcome;
2. use the target model's named tokenizer;
3. record the exact content sent to the model;
4. record current model and price identifiers;
5. measure task quality as well as input size;
6. record version, commit, corpus digest, configuration, cache state, build,
   runner, and measurement date; and
7. publish the raw or privacy-preserving per-input evidence.

Use the [public claim and evidence registry](claims) for currently allowed
wording and the [benchmark policy](https://github.com/plasmate-labs/plasmate/blob/master/docs/BENCHMARKING.md)
for new studies.
